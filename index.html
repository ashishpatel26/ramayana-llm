Why "Hanuman"

A name earned through grammar

When Hanuman first meets Rama in the Kishkindha Kanda, Rama tells Lakshmana that this messenger must have mastered grammar, because he spoke at length without a single mistake. Getting grammar right is the first thing a language model learns, and it is what this model does best.

नूनं व्याकरणं कृत्स्नमनेन बहुधा श्रुतम्।
बहु व्याहरतानेन न किञ्चिदपशब्दितम्॥ Valmiki Ramayana, Kishkindha Kanda 3.29: "Surely he has studied the whole of grammar many times; though he spoke much, not one word was wrong."

How it was built

From raw Wikipedia to weights

DownloadHindi Wikipedia (Nov 2023), 163k articles, 608 MB
CleanNFC normalisation, ≥80% Devanagari, exact dedup → 948k lines
TokenizeSentencePiece Unigram, 32k vocab, ~1.1 tokens per Hindi word
Packuint16 memmap, no padding → 55.7M train tokens
Pretrain3,500 steps × 65k tokens, bf16, cosine LR

Architecture

Try it

Run it in five lines

This is a base model: it continues the text you give it rather than answering questions. Start the prompt with <hi>.

# pip install torch transformers sentencepiece huggingface_hub

import torch, sentencepiece as spm
from huggingface_hub import hf_hub_download
from transformers import LlamaForCausalLM

repo = "ashishpatel26/hanuman-hi-42m"
model = LlamaForCausalLM.from_pretrained(repo)
sp = spm.SentencePieceProcessor(model_file=hf_hub_download(repo, "spm.model"))

x = torch.tensor([sp.encode("<hi>हिमालय पर्वत")])
y = model.generate(x, max_new_tokens=100, do_sample=True,
                   top_p=0.95, temperature=0.8, repetition_penalty=1.15)
print(sp.decode(y[0].tolist()))

Limitations

  • Facts are often made up. At 42M parameters the model has learned how Hindi is written, not what is true.
  • Wikipedia only, so the style is encyclopaedic and conversational Hindi is weak.
  • Not instruction-tuned and no safety tuning. For research and learning only.
  • Context window is 512 tokens.
